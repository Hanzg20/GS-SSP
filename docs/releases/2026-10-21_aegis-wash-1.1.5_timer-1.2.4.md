# Aegis Wash 1.1.5 / Aegis Timer 1.2.4 — 2026-10-21

Signed with the WizarPOS-certified release key (`gradlew :app:aegis-wash:signRelease`,
`:app:aegis-timer:signRelease`). Commits `3ac55f7`, `aeb5397`, `2054cc9` (plus earlier
core changes since Wash 1.1.4 / Timer 1.2.3). Installed on 253 (Wash), 254 (Timer) and 255.

## What changed

**OPC over the kiosk after a reboot** (253, 254; never seen on 255)
- WizarPOS: in socket mode (ours, port 6031) OPC starts in the foreground unless configured
  otherwise. `BootFrontGuard` (since 2026-10-09) brings the kiosk back within 3 min of boot.
- New: it reports once per boot (`app_error_logs`, code `KIOSK_COVERED_AT_BOOT`, WARNING) what it
  did and why: brought back / screen touched / not the default HOME / sent but still covered, with
  `holdsHomeRole` and `overlayPermission` (the overlay permission is what lets the background
  start on 255). Read these after 253 / 254 reboot.
- Open with WizarPOS: the setting that keeps OPC in the background in socket mode.

**Manifest changes requested by WizarPOS (Wash)**
- `com.goldsky.ssp.action.MAIN` removed from MainActivity, `LAUNCHER` from SplashActivity.
- Made safe: Splash opens MainActivity by class (`com.goldsky.ssp.MAIN_ACTIVITY` meta-data);
  AppSwitcher opens an Aegis app through its HOME entry when it has no launcher entry.
- Timer keeps its HOME `<queries>` entry (LauncherClaim, Android 11+).

**Technician panel: System check** (Wash: SYSTEM CHECK button; Timer: 系统检查)
- Status, red when wrong: network (Wi-Fi / SIM / Ethernet, IP), cloud, PAYWizard (OPC) on 6031,
  default HOME, overlay permission, clock / auto time, screen sleep, voice volume, version, up time.
- Buttons to the Android pages that fix them: Network, Home app, Overlay, Date & time, Display,
  Sound, PAYWizard.

**Timer technician page** scrolls as one page (it left a sliver to scroll on the 480 x 480 screen).

## Check on site after installing
1. Tech panel → System check: all green; **default HOME is the right app** — installing Wash on a
   terminal made it the HOME app over Timer (255, twice). Fix with the Home app button.
2. Overlay permission allowed (else the kiosk can't take the screen back from OPC after a boot).
3. Timer (254, J.E. Adams 8960 vacuum, SSAC timer): both bays coin pulses, $1.00 per pulse,
   100 ms. One pulse = one $1 coin; 2 coins to start; 2 min per coin.
4. Timer packages must match the machine: whole dollars, $2 or more, minutes = dollars × 2.
   Eagleson's $3 package is now 6 min (config `v1792551145467`); 254 shows it after a restart or
   a "sync config" from Cael.
