# Aegis Wash 1.1.13 / Aegis Timer 1.2.11 -- next releases after 1.1.11 / 1.2.10

Wash 1.1.13 also carries everything in 1.1.12 (promotion packages, buy 4 get 1) -- 1.1.12 was
built but never installed; install 1.1.13 instead. The database side (coupon migrations of
2026-11-08) is already applied, so these apps can go in any time.

## Promotion packages (Wash, from 1.1.12, owner 2026-11-03 / 11-04)
- A package whose `attributes.credit_cents` is above its price is a promotion: the customer pays
  the price, the wash runs for the credit ("8+2 MIN", gold frame, `promo_label` at the top).
- Switched-off packages (`products.is_active` false) are no longer shown.
- **Buy 4 get 1** ($16 for 20 min, `attributes.vip_bundle`): the customer is asked
  SAVE ON PREPAID CODE (default, gold) or WASH ALL NOW. Saved = the store's matching VIP load plan
  ($16 + $4) on a new never-expiring code; every wash after is a scan of it. Without that load
  plan in Cael, SAVE says unavailable -- never sells a code that wouldn't hold the 20 minutes.
  Left alone 30 s, back Home.

## Coupons (both apps, owner 2026-11-08)
- The coupon is used BEFORE the card is asked for, and given back if the card is declined /
  cancelled or the wash / vacuum does not start. Before, it was used after the card, and a
  dropped network or app left it unused (could be used again).
- A free coupon washes the basic package only: $8 picked + free coupon = the cheapest regular
  package's minutes ($4 = 4 min, "FREE WASH · 4 MIN"). A package bound to the coupon in Cael is
  run as picked.
- Checks go through the terminal's own session (coupon_check / coupon_redeem / coupon_release);
  every refusal is "This coupon can't be used"; 10 refused codes in 10 minutes and the terminal
  refuses everything until the window passes.

## Tested on 255 (2026-11-08, $0.10 card)
Wash: free coupon on $8 -> 4 pulses, no card; 98% off on $5 -> $0.10 approved, 5 pulses, coupon
used; cancelled card -> coupon given back; used free coupon -> refused.
Timer: 95% off -> $0.10 approved, vacuum on; free coupon -> vacuum on; output failure (relay
board held by Wash in the background -- only on a test terminal with both apps) -> coupon given
back, sale marked HARDWARE_ERROR, MANUAL_REFUND_NEEDED reported.
