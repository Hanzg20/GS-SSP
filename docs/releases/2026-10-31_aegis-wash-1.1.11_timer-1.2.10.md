# Aegis Wash 1.1.11 / Aegis Timer 1.2.10 -- next releases after 1.1.10 / 1.2.9

Changes: harder way into the technician screen (both), Timer's demo mode removed. Wash 1.1.11
also carries everything in 1.1.10 (Simulation Mode removed, payment page acts on the first
choice only) -- 1.1.10 was built but never installed; install 1.1.11 instead.

## Technician screen: four corners + a 6-8 digit PIN (owner, 2026-10-31)
Before: 3 taps on the version label (bottom-left of Home) within 2 s, then the store PIN --
the same corner where a no-PIN long press switched Wash into Simulation Mode on 253.
Now, on Home only: tap the four screen corners in order -- top-left, top-right, bottom-right,
bottom-left -- within 5 s, then the PIN. A tap anywhere else, the wrong order or more than 5 s
starts over; the taps still reach the screen as usual. The version label is just text now.

The PIN is the store's Cael PIN (Terminal settings -> technician PIN) and must be 6-8 digits.
A shorter one -- including the old default 1234 -- opens nothing: "No 6-8 digit technician PIN
set for this store -- set it in Cael". Cael now accepts only 6-8 digits and warns while a store
has none. **Set a 6-8 digit PIN for the store in Cael before installing**, or nobody on site
can open the technician screen.

## Timer: demo mode removed (owner, 2026-10-31)
The technician screen's "演示模式" switch is gone. It skipped the card ("DEMO — no card needed"),
drove nothing and wrote no transaction -- left on by mistake, customers would be told no card
was needed and the vacuum would not run, with nothing in the records. Sessions saved by the old
demo mode (DEMO_ refs) are still never resumed after an update.

## Install
Set the store's 6-8 digit technician PIN in Cael first. Then 253 via TMS
(`aegis-wash-1.1.11-signed.apk`), 254 via TMS (`aegis-timer-1.2.10-signed.apk`).
After installing: corners + PIN open the technician screen; one real card sale on each.
