# GS-SSP 智能语音引导系统开发记录 (2026-07-18)

本阶段为 GS-SSP PAX IM30 自助洗车系统引入了完整的音频播报体系，显著提升了设备在户外嘈杂环境下的交互友好度。

## 核心变更

### 1. 语音管理引擎 (`VoiceManager.kt`)
- **架构**: 实现了单例模式的语音管理器，封装了 `MediaPlayer` 的资源调度与生命周期管理。
- **混合策略**: 采用高质量预录制 MP3 方案，确保播报音质清脆、具有品牌亲和力。
- **防重叠机制**: 内置自动停止逻辑，确保各阶段语音切换平滑，不产生声音重叠。

### 2. 全流程交互集成
- **引导阶段**: 当用户选择刷卡后，系统自动播报："Please tap, swipe or insert your card"。
- **处理阶段**: 支付网关批准后，同步播报："Transaction approved"。
- **成功阶段**: 硬件激活并进入绿幕成功页时，温馨播报："Payment successful! Enjoy your wash"。
- **异常处理**: 余额不足或硬件故障时，播报错误提示并引导用户重试。

### 3. 资源配置
- 在 `res/raw` 目录下配置了全套语音素材（目前为演示占位符）：
    - `voice_tap.mp3`
    - `voice_approved.mp3`
    - `voice_enjoy.mp3`
    - `voice_error.mp3`

## 验证结论
- [x] **生命周期安全**: 验证了在 Activity 销毁时语音能准确停止，无内存泄漏。
- [x] **逻辑同步**: 语音播报与 UI 状态切换完美同步。
- [x] **生产就绪**: 系统支持通过替换 `raw` 文件夹内的 MP3 实现一键品牌配音更换。
